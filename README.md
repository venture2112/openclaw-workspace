# OpenClaw Workspace

This repository contains the workspace files for Venture Works Inc. managed through OpenClaw.

## Contents

- **quanivo-faq-schema.json** - FAQ schema for Quanivo Wellness
- **wellness-spas-north-county-2026-05-05.csv** - Wellness spa leads in North County San Diego
- **priority_leads.json** - Priority lead data
- **SOUL.md** - AI assistant personality and operating principles
- **USER.md** - User profile and preferences
- **AGENTS.md** - Workspace guidelines for AI agents
- **BOOTSTRAP.md** - Initial setup instructions
- **HEARTBEAT.md** - Periodic task checklist
- **IDENTITY.md** - AI identity configuration
- **TOOLS.md** - Tool-specific notes and configurations

## About

This workspace supports the business operations of Venture Works Inc., including:
- National tax business
- Quanivo Wellness (quantum energy beds and luxury wellness equipment)
- Domain portfolio management
- B2B consulting and development
